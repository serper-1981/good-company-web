GOOD COMPANY STOCK ONLINE - PAQUETE BASE PARA GITHUB + CLOUDFLARE

IMPORTANTE: No subir el ZIP original V49. Este paquete NO contiene .env, node_modules ni data.

ARQUITECTURA:
- Cloudflare Pages: publicar carpeta public; funciones en functions.
- Cloudflare KV: namespace para guardar la clave "catalogo".
- Cloudflare Pages: configurar binding KV llamado STOCK_KV al namespace.
- GitHub Actions: consulta ADMIN y publica en KV solo cuando la sincronización completa termina bien.
- GitHub Secrets: GC_ADMIN_EMAIL, GC_ADMIN_PASSWORD, GC_EMAIL, GC_PASSWORD (si aplica), CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_KV_NAMESPACE_ID, CLOUDFLARE_API_TOKEN.
- Programación UTC-3 lunes a viernes 08:00 a 16:00 cada 15 min, sujeto a demoras de GitHub.

PASOS (NO REALIZADOS):
1. Subir este paquete al repositorio privado de GitHub, conservando los archivos ocultos .github y .gitignore.
2. Crear Cloudflare KV y configurar el binding STOCK_KV en Cloudflare Pages.
3. Crear Pages conectado al repositorio: build command vacío, output directory "public"; root directory /.
4. Crear token Cloudflare con permiso de edición KV para el namespace.
5. Guardar las credenciales y los IDs como secretos de Actions; NUNCA publicarlos.
6. Ejecutar Actions > Actualizar stock Good Company > Run workflow; verificar resultado y sitio público.
7. Antes de usar con clientes, verificar filtros, impresión, imágenes y 2 ciclos de sincronización.
